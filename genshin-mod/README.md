# Teyvat Elements（提瓦特元素）

在 Minecraft 1.21.1 + NeoForge 中实现原神式元素战斗系统的 mod。
非官方同人作品，与 HoYoverse 无关；素材均为脚本生成的原创占位图。

## 玩法

### 元素法杖（创造模式「提瓦特元素」页签，7 把）

火 / 水 / 雷 / 冰 / 风 / 草 / 岩。左键攻击生物施加元素，右键对自己施加（测试用）。

### 附着规则（还原原神元素量理论）

- 附着量（GU）线性自然衰减，1.0 量值约 9.5 秒
- 新附着打 8 折（附着税）；同元素重复附着取较强者
- 同一来源的附着受 ICD 限制：3 次命中 / 2.5 秒窗口
- 风、岩不能附着，只能触发反应
- 免疫规则：火免生物挂不了火（僵尸猪灵等），冻免生物挂不了冰（流浪者等）

### 环境附着

水中/雨中 → 水；着火/岩浆 → 火；细雪 → 冰；雷击 → 雷。

### 元素反应（13 种）

| 反应 | 组合 | 类型 | 效果 |
|---|---|---|---|
| 蒸发 | 水×火 | 增幅 | 当次攻击 ×1.5（火打水）/ ×2.0（水打火） |
| 融化 | 火×冰 | 增幅 | ×2.0（火打冰/冻结）/ ×1.5（冰打火） |
| 超载 | 火×雷 | 剧变 | AoE 伤害 + 弹起 |
| 感电 | 水×雷 | 剧变 | 雷伤 + 闪电链传导给"湿的"目标 |
| 超导 | 冰×雷 | 剧变 | AoE 冰伤 + 物理抗性 -40%（限时） |
| 冻结 | 水×冰 | 控制 | 定身（冰壳外观），衰减后解除 |
| 碎冰 | 冻结+重击 | 事件 | 跳劈/爆炸解除冻结并追加物理伤害 |
| 燃烧 | 草→火 | DoT | 原版点燃 + 燃烧附着 |
| 绽放 | 草×水 | 剧变 | 生成草原核，5 秒后爆炸 |
| 超绽放 | 雷打草原核 | 剧变 | 单体高伤 |
| 烈绽放 | 火打草原核 | 剧变 | 大范围爆炸 |
| 扩散 | 风×火/水/雷/冰 | 剧变 | 把附着传播给周围生物 |
| 结晶 | 岩×火/水/雷/冰 | 护盾 | 掉结晶片，拾取转吸收心 |
| 激化系 | 草×雷 | 状态 | 激化状态 → 超激化（雷命中）/蔓激化（草命中）加算增伤，不耗状态 |

## 构建

```bash
gradlew.bat build
# 产物：build/libs/teyvat_elements-<version>.jar
```

环境：JDK 21（本机便携版见 `../local.md`）；中国大陆网络已配好镜像链（见 build.gradle 注释）。

## 架构速览

```
element/     元素枚举、附着（量值/衰减）、ICD
data/        NeoForge Attachment 存储（瞬态，不入存档）
reaction/    反应基类（三元组+类型）+ 注册表 + 13 个实现
logic/       施加入口、伤害管线、冻结/抗性/碎冰/拾取处理器
network/     S2C 附着同步
client/      头顶图标公告板、冻结冰壳渲染层、草原核渲染器
```

设计背景与版权注意事项见 `../docs_human/开源原神mod调研与实现方案.md`；
逐轮开发记录见 `../docs_agent/session/2026-11-09.md`。
