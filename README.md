# Mine Teyvat（提瓦特元素）

在 Minecraft 1.21.1 + NeoForge 中还原原神的元素战斗与武器养成系统。
非官方同人作品，与 HoYoverse 无关。

## 已实现功能

### 元素反应系统（13 种反应，还原元素量理论）

- **附着机制**：元素量（GU）、附着税（×0.8）、线性衰减（1GU≈9.5s）、ICD（3 次命中/2.5 秒窗口）
- **增幅**：蒸发（水×火 ×1.5/×2.0）、融化（火×冰 ×2.0/×1.5，冻结视作冰）
- **剧变**：超载（AoE+弹起）、感电（闪电链传导给"湿的"目标）、超导（AoE+物理抗性 -40%）、绽放（生成草原核，5 秒后爆炸）
- **超/烈绽放**：雷/火引爆草原核
- **控制**：冻结（冰壳定身，复用原版点燃的燃烧）
- **传播**：扩散（风把附着扩散给周围生物，可链式触发）
- **护盾**：结晶（岩触发掉结晶片，拾取转吸收心）
- **状态**：激化体系（原激化挂状态 → 超激化/蔓激化加算增伤，不耗状态）
- **事件驱动**：碎冰（冻结目标受跳劈/爆炸时破冰加伤）

### 环境与免疫

- 环境附着：水中/雨中 → 水，着火/岩浆 → 火，细雪 → 冰，雷击 → 雷
- 元素免疫：火免生物挂不了火，冻免挂不了冰（复用原版伤害免疫规则）

### 武器养成

- **升级**：铁砧 + 精锻矿（杂 +1 / 良 +2 / 魔 +10 级），到顶截断
- **突破**：铁砧 + 突破石，四阶制 Lv.20/40/60/90，60 级突破换升阶模型
- **刻印**（圣遗物五件套）：生/死/时/空/理五槽镶嵌 GUI（潜行+右键武器），
  属性含生命/攻击/攻速/元素精通/暴击率
- **元素战技**：武器右键释放（护摩：前方扇面火附着，5s 冷却）
- 材料经济：魔晶矿（主世界 y-16~64，铁镐）掉落三档精锻矿，2 杂合 1 良、4 良合 1 魔

### 自定义属性

物理抗性 / 元素精通（反应收益 1+EM×0.002）/ 暴击率（暴击 ×1.5）

### 表现层

头顶元素图标（随量值变淡）、环绕粒子、冻结冰壳渲染、草原核实体、反应动作条提示、中英繁三语言

## 构建

```bash
cd genshin-mod
gradlew.bat build   # 需 JDK 21；产物在 build/libs/
```

中国大陆网络已内置镜像链（creeperhost / forgecdn / 阿里云），无需代理。
本机环境备忘见 `local.md`（gitignored）。
